# A4: Port-Drift finden (Wunsch)

Ich möchte sehen, wo die Portliste und der Code meiner Projekte auseinanderlaufen. portwart soll einen Ordner mit
Projekten nur lesend nach Port-Angaben durchsuchen, etwa `--port 8766`, `PORT=8766`, `:8766` in einer URL oder
`port = 8766` in einer Konfigurationsdatei. Das Ergebnis vergleicht es mit `ports.toml`: Gemeldet werden Ports, die im
Code stehen, aber nicht in der Liste, und eingetragene Projekte, deren Code einen anderen Port nennt als die Liste.
Verändert wird dabei nichts, weder in den Projekten noch in der Liste.
