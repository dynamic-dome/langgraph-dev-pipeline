# A8: Port austragen (Wunsch)

Fällt ein Dienst weg, lösche ich seinen Eintrag bisher von Hand aus `ports.toml`. Ich möchte einen Befehl dafür:
`portwart austragen <name>`. Entfernt wird nur dieser eine Eintrag; Kommentare, Reihenfolge und alle übrigen
Einträge bleiben, wie sie sind, und eine halb geschriebene Datei darf es nie geben. Gibt es den Namen nicht, wird
abgelehnt, mit einer klaren Meldung. `pruefen`, `abgleich`, `frei`, `drift` und `eintragen` sollen sich nicht
verändern.
